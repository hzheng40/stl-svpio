# Paper Configs

This directory contains the curated configurations used for the public
reproduction entrypoints.

- `table1_reach_avoid.yaml`: Table I / Figure 2 single-agent reach-avoid.
- `stl_svpio_pointmass.yaml`: STL-SVPIO configs for Figure 3 point-mass tasks.
- `svmpc_pointmass.yaml`: SVMPC baseline configs for Figure 3.
- `dpi_pointmass.yaml`: DPI baseline configs for Figure 3.
- `stlcg_gradient_descent_pointmass.yaml`: STLCG++-style direct gradient descent baseline configs.
- `milp_pytelo_pointmass.yaml`: optional PyTeLo/Gurobi MILP tasks.
- `nonlinear.yaml`: Panda and Half-Cheetah MJX reproduction metadata.
